Aktuelle Version: 0.4.0

App herunterladen

  1. Die heruntergeladene Datei in der App «Dateien» öffnen (Ordner «Downloads»). Der Download-Dialog des Browsers verweigert das Öffnen oft.
  2. Die neue Version wird über die alte installiert. Die Messwerte bleiben erhalten.

Die installierte Version wird nur im Browser verglichen; der Teil nach dem # wird nicht an den Server gesendet.

Mehr zur Installation und die Prüfsumme der Datei stehen auf der Startseite.
