Offline-Version herunterladen

  1. Die heruntergeladene Datei in der App «Dateien» öffnen (Ordner «Downloads»). Der Download-Dialog des Browsers verweigert das Öffnen oft.
  2. Die neue Version wird über die alte installiert. Die Messwerte bleiben erhalten.

Wer Messwerte für die Lärmkarte teilen möchte: Karten-Version herunterladen. Sie wird über die installierte Version installiert, die Messungen bleiben erhalten. Welche Version?

Die installierte Version wird nur im Browser verglichen; der Teil nach dem # wird nicht an den Server gesendet. Die App-Dateien liefert GitHub aus.

Mehr zur Installation und die Prüfsummen der Dateien stehen auf der Startseite.
