Stadtlärm offline herunterladen

Misst und behält alles auf dem Telefon. Keine Internet-Berechtigung.

Stadtlärm mit Lärmkarte herunterladen

Zusätzlich freiwilliges «Messwerte teilen» für die gemeinsame Karte (ausgeschaltet, bis Sie es einschalten).

Lieber ganz ohne Internet? Stadtlärm offline herunterladen. Vorher in der App unter «Einstellungen → Messwerte teilen» auf «Meine Daten auf dem Server löschen» tippen, denn die Offline-Ausgabe kann das nicht.

Bei der Lärmkarte mitmachen? Stadtlärm mit Lärmkarte herunterladen. Sie installiert sich über diese Ausgabe und behält die Messwerte.

  1. Die heruntergeladene Datei in der App «Dateien» öffnen (Ordner «Downloads»). Der Download-Dialog des Browsers verweigert das Öffnen oft.
  2. Die neue Version wird über die alte installiert, auch wenn Sie die Ausgabe wechseln. Die Messwerte bleiben erhalten.

Die installierte Version wird nur im Browser verglichen; der Teil nach dem # wird nicht an den Server gesendet.

Mehr zur Installation und die Prüfsumme der Datei stehen auf der Startseite.
