Datenschutz

Diese Website

stadtlaerm.ch besteht aus wenigen statischen Seiten. Sie setzt keine Cookies und lädt nichts von Dritten: keine Schriften, keine Skripte, keine Bilder und keine Statistik- oder Analysedienste – mit einer Ausnahme, der Lärmkarte. Das Projekt erfährt nicht, wer die Seite besucht.

Ausnahme ist die Seite «Lärmkarte»: Diese Seite lädt die Kartenbilder von swisstopo und die Messwerte von api.stadtlaerm.ch, sonst nichts von anderen Servern. Dabei erfahren swisstopo (Bundesamt für Landestopografie) und der Server des Projekts technisch bedingt Ihre IP-Adresse; die Seite sendet keine Herkunftsadresse (Referrer) mit und setzt keine Cookies. Der Server des Projekts führt kein Zugriffsprotokoll.

Ausserdem enthält die Seite «Update prüfen» enthält ein kleines Skript. Die App öffnet sie im Browser und hängt die installierte Version an die Adresse an, nach einem #. Diesen Teil der Adresse sendet der Browser nicht an den Server; der Vergleich mit der aktuellen Version findet nur im Browser statt.

Die Website wird über GitHub Pages bereitgestellt (GitHub, Inc.). Beim Aufruf verarbeitet GitHub technisch bedingt Daten wie die IP-Adresse, zum Beispiel für Betrieb und Sicherheit. Dafür gilt das GitHub General Privacy Statement. Dasselbe gilt für Links auf github.com, etwa zum Quellcode.

Die App

  • Der Ton vom Mikrofon wird nur im Arbeitsspeicher ausgewertet, in kleinen Zwischenspeichern von höchstens etwa einer Sekunde, die laufend überschrieben werden. Es wird nie Audio gespeichert.
  • Gespeichert werden nur Pegel und Statistiken: Lärmpegel pro Minute, laute Ereignisse (Zeit, Dauer, Spitzenpegel, wahrscheinliche Quelle) und Kalibrierungen. Diese Daten liegen nur auf Ihrem Telefon.
  • Die App hat keine Internet-Berechtigung und überträgt nichts. Es gibt keine Statistikdienste, keine Absturzberichte und keine Sicherung in die Cloud. «Nach Update suchen» öffnet nur die Seite «Update prüfen» im Browser.
  • Die Erkennung der Lärmquelle läuft auf dem Telefon. Sie hält fest, welche Art von Geräusch vorkam (etwa «Stimmen»), nicht was gesagt wurde.
  • Daten verlassen das Telefon nur, wenn Sie selbst eine CSV-Datei exportieren und teilen. Bedenken Sie dabei: Ein Eintrag wie «Stimmen, 23:41» verrät, dass um diese Zeit in der Nähe gesprochen wurde.
  • Löschen können Sie die Daten in der App unter «Daten» oder indem Sie die App deinstallieren.

Wie der Quellcode diese Zusagen umsetzt und wie man sie nachprüft, steht in PRIVACY.md (Englisch).
